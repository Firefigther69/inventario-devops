Como no hay un segundo integrante, cada pull request se revisa con:
1. Los checks obligatorios del CI (lint, auditoría, pruebas, validación IaC, imagen y título del PR).
2. Una autorrevisión documentada en la plantilla del PR (checklist) antes del *squash merge*.
3. La aprobación manual del ambiente `production` antes de cada despliegue.

Los aportes se verifican en *Insights → Contributors*, la pestaña *Pull requests* y `git shortlog -sne`.
